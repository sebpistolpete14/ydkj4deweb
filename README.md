YDKJ 4 DE/YDKJ Vol. 6: The Lost Gold in your web browser!

To host, simply run the server.py file. It should be hosted at localhost:8000
If you want to run YDKJ 6 instead of YDKJ 4 DE, simply copy over the game files (engine.dat, the "lib" folder) into a new folder. Name it something like "ydkj6". Copy over index.html, and rename "engine.dat" to "engine.swf". The game should now run if you go to "localhost:8000/ydkj6".
Other info is in the index.html file used to run the game
