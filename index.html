GET FLASH!

If you can't see the above, then read this!

Due to Adobe Flash Player's retirement, you will need to install CleanFlash, which installs the Chinese version of Flash Player onto your computer, along with a companion browser.

Why use the Chinese version? Well, after Flash's death internationally, the version released in China still got updates, up to version 34. CleanFlash is that version, but in English, and with the spyware that the original Chinese version had removed.

Why do I need to install another browser? Most mainstream browsers dropped support for Adobe Flash Player along with the plugin interfaces that it used (PPAPI and NPAPI). As such, you will need to acquire an older browser.

Please note that when using Flash:

1. Flash may perform poorly on lower end PCs, and generally could cause the page to be unresponsive

2. Some newer versions of Flash might be slower / glitchier
